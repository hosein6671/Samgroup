# Base Oils Content Source Record

**Status:** Editorial source record — not a SAM product specification  
**Reviewed:** 2026-08-28  
**Public page:** `/en/products/base-oils`

## Publication boundary

The public page may explain established industry classification and selection concepts. It must not copy another producer's typical values, imply that a competitor's data sheet describes a SAM product, or publish a SAM property value before the corresponding SAM TDS has passed technical review.

The product names and range structure remain those already approved in the repository. No formulation or product designation is changed by this content pass.

## Primary sources used

1. American Petroleum Institute, **API 1509 Documents**, current edition listed as _API 1509, Engine Oil Licensing and Certification System, 24th Edition, July 2026_: <https://www.api.org/products-and-services/engine-oil/documents/api-1509-documents>
   - Used for the existence and current status of the API 1509 base-stock grouping framework.
   - Group I–III are distinguished using saturates, sulfur and viscosity index.
   - Group III includes the viscosity-index boundary of 120 or higher.
   - Group IV is PAO; Group V contains base stocks outside Groups I–IV.
   - Manufacturing route alone does not determine the group; analysed properties do.

2. Saudi Aramco, **Base oils – Aramco Dura, Aramco Prima, and Aramco Ultra**: <https://www.aramco.com/en/what-we-do/energy-products/refined-products/base-oils>
   - Used only to corroborate industry application language for Group I–III base oils.
   - No Aramco product name, performance claim, or numerical property has been transferred to a SAM product.

3. Nynas, **Base oils**: <https://www.nynas.com/no/products/base-oils/>
   - Used only to corroborate general selection language around naphthenic oils, solvency, low-temperature behaviour and industrial formulation contexts.
   - No Nynas grade, performance claim, or numerical property has been transferred to a SAM product.

## Deliberately excluded from public product specifications

- Competitor TDS values for SN 150, SN 500, BS 150 or any similarly named grade.
- Unverified SAM viscosity, viscosity index, flash point, pour point, colour or density values.
- Production-origin, refinery, capacity, MOQ, lead-time, certification or market-coverage claims not approved in SAM source material.

These fields remain pending until SAM-owned technical documentation is registered and approved through the technical-content gate.
